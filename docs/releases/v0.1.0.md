# Smart Agro AI v0.1.0 Release Notes

Date: 2026-06-04

Release type: open-source MVP baseline.

Smart Agro AI v0.1.0 prepares the repository as a public, test-backed MVP for review, contribution, and future hosted demo work. It is not a production release and should not be presented as production agronomic advice.

## Highlights

- Security/runtime cleanup, `.env.example` files, ignored local databases, and safer repository hygiene.
- OSS workflow baseline with CI, issue templates, pull request template, contributing guidance, security policy, roadmap, and changelog.
- Modular FastAPI backend with validation hardening, stable API contracts, service-level tests, and explicit fallback metadata.
- JWT-based MVP authentication with registration, login, `/api/me`, frontend session restore, and protected frontend views.
- Alembic migration support, initial users-table migration, and an idempotent local-only demo seed workflow.
- Frontend polish for auth/session handling, API error states, accessibility helpers, demo labels, and production-demo copy consistency.
- Playwright browser smoke tests covering landing, auth, session restore, analysis, mobile navigation, and lightweight accessibility behavior with mocked backend responses.
- Frontend dependency audit cleanup, code splitting, and chart layout stabilization.
- ML audit, dataset card, model card, deterministic candidate training workflow, metrics baseline, label mapping contract, artifact metadata, and promotion gate.
- Dataset governance policy and download-only/user-provided dataset workflow for unresolved dataset source/license status.
- Deployment readiness documentation, environment variable matrix, runtime command guidance, and public demo checklist.

## Known Limitations

- This is an open-source MVP baseline, not a production-ready system.
- Authentication is MVP-grade: no refresh tokens, MFA, email verification, password reset, or production rate limiting.
- Frontend token storage uses `localStorage`; this is documented as MVP-only.
- `dataset/Crop_recommendation.csv` has unresolved source/license status and is not tracked by Git.
- Model artifacts remain MVP/demo-only. Candidate artifacts are not promoted while dataset provenance/license remains unresolved.
- Model metrics are reproducibility records, not field validation or agronomic reliability claims.
- Marketplace, support, admin, IoT, virtual agronom, payment/subscription, and several history/report areas remain demo/static or simulated.
- No hosted public deployment is included in this release preparation phase.

```powershell
.\backend\venv\Scripts\python.exe -m backend.scripts.seed_demo
```

Frontend:

```powershell
cd frontend
npm ci
npx playwright install chromium
npm run build
```
