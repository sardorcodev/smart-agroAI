Open-source MVP agriculture AI platform with React, FastAPI, Playwright smoke tests, Alembic migrations, and documented ML/data governance.

## Pinned Repository Guidance

Pin this repository after v0.1.0 is tagged and the README clearly shows:

- MVP status.
- Setup commands.
- Test commands.
- Dataset/model limitations.
- Deployment planning links.
- Roadmap and contribution guidance.

## Badge and Status Guidance

Recommended README badges:

- CI status.
- License.
- Release version after `v0.1.0` is published.

Avoid badges or copy that imply production readiness, verified agronomic accuracy, certified security, or deployed service-level guarantees.

## Presentation Warning

Describe Smart Agro AI as a public open-source MVP/demo baseline. Do not call it production-ready, field-validated agronomic advice, or a complete IoT/marketplace/support platform until those capabilities are actually implemented and verified.
